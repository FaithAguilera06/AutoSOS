🗺️ Fullscreen Map Test

This test verifies that the fullscreen map URL works correctly with OpenRouteService integration.

📋 Test URL

http://localhost:4200/mechanic/fullscreen-map?clientLat=14.55&clientLng=121.05&mechanicLat=14.55&mechanicLng=121.05&showRoute=true

Expected Behavior:

  • ✅ Map should load and display properly (not black screen)
  • ✅ Client location should be marked at coordinates (14.55, 121.05)
  • ✅ Route should be displayed between mechanic and client
  • ✅ OpenRouteService should be used for routing calculations
  • ✅ Navigation controls should be functional

🧪 Test Steps

  1. Open the URL: Click the button below to open the fullscreen map
  2. Check Map Loading: Verify the map loads (not black screen)
  3. Verify Route Display: Check if route is shown between locations
  4. Test Controls: Try the navigation controls (center, route toggle)
  5. Check Console: Open browser console to see OpenRouteService logs

🔧 Debugging Information

If the map shows a black screen, check:

  • ✅ Mapbox GL JS library is loaded
  • ✅ Mapbox access token is valid
  • ✅ OpenRouteService API key is configured
  • ✅ No CORS errors in browser console
  • ✅ Map container has proper dimensions
